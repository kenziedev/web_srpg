# v0.1 검토와 v0.2 변경 기록

2026-09-08. 사용자 요구의 중심은 **고전 랑그릿사2의 시스템, 가벼운 도트 웹 게임, 빠른 플레이, 클리어를 위해 고민할 상황**이다. 원안의 풍부한 전직·세계관 아이디어는 보존하고, 먼저 이 네 가지를 검증할 설계를 현행 문서로 분리했다.

## 1. 원안에서 유지한 것

지휘관과 독립 용병, 지휘 범위, 병종 상성, HP 10, 분기 전직, 정보 공개, 결정론적 규칙 코어, 원작과 별도의 세계관·표현, 로컬 우선 저장을 유지한다. 오르덴·카이엘 등의 가칭과 100종 직업 아이디어는 v0.1에서 계속 참고할 수 있다.

## 3. 레퍼런스의 기준과 확인 범위

**Mega Drive의 Langrisser II와 Super Famicom의 Der Langrisser를 같은 판본으로 간주하지 않는다.** 전자는 1994년 작품, 후자는 다중 경로를 포함한 리메이크로 설명된다. 초안의 루트 분기 설명은 후자 계열의 참고로 분리한다. 판본 개요는 [Langrisser II 문서](https://en.wikipedia.org/wiki/Langrisser_II)를 보조 자료로 확인했다.

시리즈의 지휘 범위와 회복 명령 개요는 [Langrisser 시리즈 문서](https://en.wikipedia.org/wiki/Langrisser)를 참고했다. 다만 **이번 조사에서 원작 랑그릿사2 매뉴얼·실행 검증으로 상세 수치를 대조하지는 못했다.** 인접 회복량, 지휘 반경·보정, 상성 계수, 동시 교전, EXP·정비 수치는 이 프로젝트의 선택이며 원작 고증 완료로 표시하지 않는다. 원작의 정확한 계산 재현이 필요해지면 판본을 먼저 정하고 별도 검증 과제로 진행한다.

기술 버전은 [Phaser 공식 다운로드](https://phaser.io/download/phaser4)로 확인했다. 초안의 4.1까지 출시되었다는 서술은 현행 기준으로 쓰지 않으며, 실제 구현에서는 설치 시점의 릴리스·호환성을 재확인하고 버전을 고정한다. 기술 성능 목표는 우리 프로젝트의 검증 예산이며 Phaser가 해당 수치를 보장한다는 뜻은 아니다.

## 4. 확정한 구조와 실험할 수치

| 현행 구조 | 실험 후 조정할 초기값 |
|---|---|
| 지휘관·용병 개별 이동, 소속 지휘 보정 | 반경 3, AT·DF +2 |
| 부상 용병 교대와 인접 회복 | HP +3, 정비 MP +2 |
| 확정 피해와 동시 교전 | 상성 1.25/0.75/1.5, HP 계수 0.5~1 |
| 지휘관 격파로 부대 제거 | 직접 격파/퇴각 EXP 비율 |
| 장별 작전비로 최소 편성 확보 | 4인 맵 기본 1,600, 생존 할인 20% |
| 전직으로 이동·고용·지휘 역할 분기 | 18직업의 구체 성장표·장별 EXP |
| 짧은 조작·공개된 위협·복구 가능한 저장 | 15~25분 전투, 성능 예산 |

시뮬레이션·사람 플레이는 아직 수행하지 않았다. 이번 개정에서 확인할 수 있는 것은 문서 연결, 숫자 계산, 배치 좌표·지휘 거리·목표 경로 같은 정적 일관성이다. 실제 난이도·재미·브라우저 성능은 전투 검증판 단계에서 기록해야 한다.

이번 개정의 정적 검산 결과: 현행 문서 6개의 상대 링크·코드 블록 닫힘·문자 인코딩, 피해 예시 9개, 첫 맵 유닛 24기의 좌표 중복·경계·초기 소속 지휘 거리, 기본 편성 비용 1,500, 봉화 경로 비용 7, 방해 없는 호송대 이동 9페이즈를 확인했다. 규칙 엔진이나 전체 맵 클리어 테스트를 실행한 결과는 아니다.

## 5. 에셋과 외부 서비스

최종 게임에는 프로젝트용으로 제작하거나 사용 조건을 확인한 에셋을 넣고, 파일·출처·라이선스·표기 요구를 대장으로 관리한다. 초안의 법적 단정은 현행 설계 근거로 사용하지 않는다. 이번 개정은 법률 검토나 에셋 사용 허가 확인을 수행한 작업이 아니다.

계정·클라우드·랭킹은 MVP 밖이다. 서비스가 실제로 필요해질 때 인증 제공자·요금·개인정보 처리·서버 검증을 별도 문서로 설계한다. 초안의 무료 티어·제공자 지원·정책 설명을 구현 시점의 사실로 가정하지 않는다.
