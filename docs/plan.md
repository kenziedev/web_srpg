# 오르덴 연대기 제작 계획 v0.2

작성일: 2026-09-08 · 상태: 구현 가능한 설계안, 밸런스 미검증

## 1. 만들려는 게임

**지휘관을 한 칸 옮기는 선택이 부대 전체의 전선을 바꾸는, 가볍게 켜고 깊게 고민하는 웹 SRPG.** 지휘관과 용병은 각각 맵 위에서 이동·공격한다. 병종 상성만 맞추는 데서 끝나지 않고, 지휘 범위 안에 머물기, 부상 병력을 뒤로 돌리기, 적 지휘관을 노출시키기, 서로 떨어진 목표에 병력을 나누기를 함께 판단한다.

고전 랑그릿사2 계열의 부대 운용 감각을 설계 기준으로 삼는다. 특정 판본의 수치·버그까지 그대로 재현하는 프로젝트는 아니다. 원작 판본 구분과 확인 범위는 [검토 기록](design-review.md)에 적는다. 캐릭터·지도·이야기·아트는 이 프로젝트의 것으로 만든다.

플레이어가 전투 뒤 “레벨을 더 올려야겠다”보다 “창병을 다리에 남기고 지휘관은 숲 쪽으로 옮길걸”이라고 생각하게 만드는 것이 목표다.

| 우선순위 | 원칙                      | 실제 설계 결정                                                 |
| -------- | ------------------------- | -------------------------------------------------------------- |
| 1        | 부대를 지휘하는 재미      | 독립 용병, 소속 지휘 보정, 인접 회복, 지휘관 격파 시 부대 퇴각 |
| 2        | 공개된 정보로 어려운 선택 | 확정 피해, 적의 이동·사거리, 증원 예고, 목적이 다른 전선       |
| 3        | 빠른 접근·조작·재도전     | 무계정 시작, 15~25분 전투, 자동 저장, 짧은 맵 내 연출          |
| 4        | 도트의 명료함             | 작은 스프라이트, 병종 실루엣, 깃발과 숫자, 읽기 쉬운 한글 UI   |
| 5        | 성장으로 운용 변화        | 전직이 이동·고용 병종·지휘 특화를 바꿈; 직업 수는 검증 뒤 확장 |

## 2. 핵심 경험과 대가

| 상황                                  | 유리한 선택                          | 함께 발생하는 대가                          |
| ------------------------------------- | ------------------------------------ | ------------------------------------------- |
| 지휘관을 전진시켜 범위를 확장         | 용병들이 보정을 받으며 목표 접근     | 적 기병·궁병의 지휘관 공격 경로가 열림      |
| HP가 줄어든 용병을 지휘관 옆으로 복귀 | 다음 아군 페이즈에 회복, 화력 복구   | 전열 한 칸과 이번 공격 기회를 비움          |
| 적 지휘관 먼저 격파                   | 소속 용병까지 일시에 퇴각, 빠른 돌파 | 남은 용병을 직접 격파할 EXP 일부 포기       |
| 용병부터 격파                         | 적 화력 감소, 소속 지휘관 성장       | 적 지휘관이 후퇴·치유할 시간 발생           |
| 고급 비병을 고용                      | 강·산 우회, 궁병 뒤를 공격           | 높은 비용과 궁병 특효 때문에 별도 보호 필요 |
| 지휘 범위 안에 밀집                   | 모두 보정, 부상자 교대 쉬움          | 광역 마법에 동시 피해, 길목 혼잡            |
| 여러 목표로 부대 분리                 | 호위와 봉화 차단을 동시에 수행       | 지원 마법·지휘 범위 공유 불가               |

위 상황이 실제 맵에서 나오지 않으면 직업과 콘텐츠를 늘리기 전에 맵을 고친다. 지휘관 단독으로 모든 목표를 쉽게 해결하거나, 매번 용병 전체를 지휘관 주위에 뭉치는 것만 최적이라면 핵심 설계 실패다.

## 4. 플레이 흐름

1. **정찰:** 다음 맵 전체 지형, 적 편성·지휘관 직업, 승패 조건, 예고된 증원을 확인한다.
2. **편성:** 출격 지휘관, 용병과 장비를 선택한다. 고용비 총액과 남은 작전비를 즉시 표시한다.
3. **전투:** 지휘관·용병을 자유 순서로 이동 후 행동시킨다. 아군 → 적 → NPC → 라운드 종료 순서다.
4. **정산:** 처치·피해·목표 기여 EXP, 작전 보상, 생존 용병을 확인한다.
5. **성장:** 레벨업·전직·장비 교체 후 다음 장으로 간다. 짧은 대화는 건너뛰고 다시 읽을 수 있다.

한 전투 15~~25분, 첫 튜토리얼 5~~10분, 마지막 전투 최대 30분을 목표로 한다. 준비 2~~3분, 일반 맵 6~~10라운드가 기준이다. 사고 시간에는 제한을 두지 않는다. 짧은 플레이는 클릭·대기·재시작 비용을 줄여 달성한다.

## 5. 랑그릿사다운 전투의 기준

전체 수치와 예외 처리는 [전투 규칙](combat-rules.md)이 기준이다.

- 지휘관은 본인과 다른 지휘관에게 지휘 보정을 주지 않는다. **자기 용병**에게만 준다.
- 지휘 범위는 반경 3 맨해튼 거리, 기본 AT·DF **고정값 +2**. 전직은 범위 또는 보정 성격을 바꾼다. 작은 스탯에서 범위 안팎의 차이가 읽히게 한다.
- HP는 모두 10. 피해와 화력 감소를 정확히 예측한다. 기본 공격은 쌍방의 교전 직전 HP를 사용해 피해를 동시에 확정한다. 근접 돌입에는 대가가 남는다.
- 아군 페이즈 시작 시 지휘관에 상하좌우 인접한 소속 용병은 HP 3 회복. 지휘관의 제자리 `정비`는 자신 HP 3·MP 2 회복을 위해 행동 전체를 쓴다.
- 보병 > 창병 > 기병 > 보병, 궁병의 비병 특효, 수병의 수상 우위를 먼저 읽히게 한다. 마법은 밀집 진형을 깨고 방어적 대기를 압박한다.
- 지휘관 HP 0이면 소속 용병은 즉시 퇴각한다. 전장의 위협을 제거하는 지름길이 되지만 퇴각 용병의 처치 EXP를 전부 받지는 않는다.
- 양 진영이 같은 이동·상성·회복·MP·피해 규칙을 쓴다. 적만 무료 회복하거나 지휘 범위를 무시하지 않는다.

## 6. 전직과 성장

**현행 0.7:** 아래의 기여 EXP·승리 1회 정산·고정 성장·18직업·레벨별 마법 학습·메사이얀 소드·룬스톤을 구현했다. 초기 세 지휘관은 Lv1·EXP0이며 기존 전장 능력치와 미라의 4마법은 유지한다. 전투 중 성장은 없고 정산 뒤 명부에 적용한다. 첫 맵의 기존 검증 경로는 Lv10에 도달하지 않으며 초기 EXP를 높이지 않았다. 현행 명령·예외·저장 계약은 [성장 구현 기준](growth-system.md)을 따른다. 아래의 고용 병종·마스터리·장별 성장 속도는 캠페인 후속 설계다.

### 6.1 MVP 직업 트리

비병·수병이 초안처럼 4차나 미구현 도적 계열에 묶이지 않게 첫 공개판에서 열어 둔다. 6명의 시작 역할이 각각 아래 한 계열을 담당한다. 명칭은 가칭이다.

| 1차 → 2차                      | 이동·지휘의 변화                                    | 고용 가능한 용병                        |
| ------------------------------ | --------------------------------------------------- | --------------------------------------- |
| 영주 → 전열대장 / 유격영주     | 전열: 보행 4, 범위 4 / 유격: 보행 5, 범위 3         | 전열: 보병·창병·궁병 / 유격: 보병·궁병  |
| 전사 → 철벽병 / 돌격대장       | 철벽: 보행 3, 지휘 DF +3 / 돌격: 보행 4, 지휘 AT +3 | 양쪽 보병·창병; 돌격에 기병 추가        |
| 기사 → 중기사 / 비행기사       | 중기사: 기승 5, 지휘 DF +3 / 비행: 비행 6, 범위 3   | 중기사: 기병·창병 / 비행: 비병·보병     |
| 정찰병 → 장궁대장 / 수군대장   | 장궁: 보행 4, 사거리 2~3 / 수군: 수륙 5             | 장궁: 궁병·보병 / 수군: 수병·궁병       |
| 마도사 → 원소술사 / 마도지휘관 | 원소: 지역 피해 마법 / 지휘: 범위 4, 지원형         | 양쪽 보병·궁병                          |
| 수도사 → 주교 / 성전사         | 주교: 힐·포스 힐 상위 단계 / 성전사: 보행 5, 근접형 | 주교: 성직병·창병 / 성전사: 성직병·보병 |

마도지휘관은 지휘 범위 4와 소속 용병 RES +2를 가진 지원형이다. 원소술사와 달리 지역 피해 마법은 배우지 않는다. 표에서 별도 언급이 없으면 보행 4, 범위 3, 지휘 AT·DF +2, 근접 사거리 1이다. 마법 사거리는 마법 데이터가 결정한다. 전직의 유리한 점과 잃는 점을 같은 화면에서 비교한다.

### 6.2 성장 속도와 EXP

직업 Lv1부터 Lv10까지 레벨당 100 EXP. 2차로 전직하면 Lv1, 기존 스탯 유지, 지정 스탯 하나 +1, 이동·고용 목록·역할 스킬 교체. 첫 전직은 3장 종료~4장 시작, MVP 최종장은 2차 운용을 시험하도록 배치한다. 이 속도가 나오지 않으면 장별 EXP 예산을 먼저 수정한다.

각 캐릭터는 레벨별 고정 성장표를 가진다. 확률 성장과 무한 레벨링은 없다. 1차 Lv1→10 동안 AT·DF·MAG·RES 증가 합계 4를 초기 상한으로 두고, 낮은 HP에 비해 공격 수치가 폭증하지 않도록 한다. 전직이 병종·지휘·역할을 바꾸는 것이 보상의 중심이다.

EXP는 전투 종료 시 한 번 정산한다. 용병의 피해·처치 기여는 **소속 지휘관에게 100%** 귀속된다. 지휘관에게 막타를 몰아줄 이유를 줄인다.

| 기여                    | EXP 초깃값           | 반복 획득 제한                                                                 |
| ----------------------- | -------------------- | ------------------------------------------------------------------------------ |
| 적에게 실제 피해        | HP 1당 2             | 동일 적 유닛에서 피해 EXP 최대 20; 적 회복으로 초기화하지 않음                 |
| 용병 직접 격파          | 20                   | 해당 개체 1회                                                                  |
| 지휘관 격파             | 60                   | 해당 개체 1회, 동시 격파도 귀속 명확히 기록                                    |
| 지휘관 격파로 용병 퇴각 | 1기당 5              | 직접 격파 20을 중복 지급하지 않음                                              |
| 아군의 실제 HP 회복     | HP 1당 2             | 소속과 무관하게 시전자에게, 지휘관 1명당 전투 합계 30까지; 정비·자동 회복 제외 |
| 장 클리어               | 180, 출격 지휘관마다 | 장 1회. 보너스 목표 EXP는 없고 작전비로 보상                                   |

격파 EXP는 마지막 피해 원인 소유자에게 준다. 소유자가 없는 지형 피해는 누구에게도 주지 않는다. 원작의 EXP 수치·성장 방식까지 복제하는 결정은 하지 않았으므로 아래 정산 방식은 프로젝트 설계로 유지한다. 전투 중 성장으로 예측을 바꾸지 않는다. 1차 Lv10 이후 초과 EXP는 최대 100을 보관해 전직 뒤 적용한다. 전직 미루기로 무제한 비축하지 않는다.

**후속 설계:** 마스터리는 1차 Lv10에 획득하는 계열별 패시브 1개, MVP 장착 슬롯 1개로 제한한다. 영주(범위 +1), 전사(자신 DF +1), 기사(평지·도로만 3칸 이상 이동한 공격의 AT +1), 정찰병(숲 이동비 1), 마도사(최대 MP +2), 수도사(자신 RES +1)부터 검증한다. 기본 보정과 합산하되 MVP 지휘 범위 상한은 4다. 원안은 전직을 준비 중 미리 바꿔 보고 **다음 출격 확정 시 경로를 고정**하는 방식이다. **현행 0.7은 후보 비교 후 전직 확정 즉시 경로를 고정한다.** 출격 전 자유 재선택과 마스터리는 구현하지 않았다. 마도지휘관의 소속 용병 RES +2는 클래스 효과로 적용한다.

전직은 Lv10에서 현재 직업이 지정한 후속 직업만 허용한다. 기존 능력치·배운 마법을 유지하고 보관 EXP 최대 100은 전직 뒤 적용한다. 2차 Lv10에 룬스톤 한 개를 소모하면 초기 직업 Lv1로 복귀하며 능력치·학습을 유지하고 보관 EXP는 0으로 만든다. 준비 중 현재 칸에 새 이동형이 착지할 수 없는 전직은 전체 거절하며, 부적합 장비는 소유 수량을 유지한 채 해제한다. 룬스톤 조건과 보관 처리 역시 프로젝트 선택이며 구 PC판의 모든 전직 동작을 복제한 것이 아니다.

## 7. 경제: 편성의 대가를 남기고 캠페인 막힘을 막는다

작전비와 영구 장비 자금을 구분한다. 초기 잔고 1,000에서 손실과 치료비가 연쇄적으로 쌓이는 초안의 구조를 바꾼다.

- **작전비:** 해당 장 용병 고용 전용. 장마다 기본 지급, 미사용액 소멸. 편성 취소·교체는 출격 전 전액 환불한다.
- **지원금:** 이번 장 보너스 목표 달성 시 다음 장 +100 또는 +200, 최대 +200. 중첩 누적되지 않는다.
- **생존 계약:** 이전 장 생존 용병은 같은 지휘관·병종으로 재고용할 때 비용 20% 할인. 장 종료 시 HP와 무관, 병종·개수만 기록하고 다음 출격 때 계약을 교체한다. 지휘관 패배로 퇴각한 용병은 할인 대상이 아니다. 고용 목록에서 사라졌다면 권리가 만료된다.
- **장비 자금:** 클리어 고정 지급. 소모 손실과 독립이다. 반복 플레이로 자금·EXP·지원금을 중복 수령할 수 없다.
- **최저 편성 검증:** 보너스·할인이 전혀 없어도 모든 장의 기본 작전비로 필수 병종을 포함한 클리어 가능 편성이 나와야 한다.

보병 100 / 창병 110 / 기병 160 / 궁병 130 / 비병 220 / 수병 140 / 성직병 150이 고용비 초기값이다. 예를 들어 지휘관 4명×용병 3기에서 보병 3 + 창병 3 + 기병 3 + 궁병 3 = **1,500**. 기본 작전비 1,600이면 이 편성이 가능하고, 비병 비중이나 4번째 용병 슬롯을 늘리려면 다른 곳을 줄인다. 4인 맵 기본 예산은 1,600부터 검증한다. 언데드는 MVP 적 전용이다.

장비 라인업은 구 Windows PC판 랑그릿사 2의 34항목·35데이터 슬롯(홀리 로드 중복) 기준이다. 현행 0.7은 각 한 개의 검증용 인벤토리, 무기·방어구/장신구 2슬롯, 각 출격 첫 전투 명령 전 장착·해제·연습 마법 편성을 구현했다. 33종의 장착 효과와 룬스톤의 소모 효과를 지원한다. 메사이얀 소드는 장착한 지휘관과 소속 부대의 전투 기여만 2배로 만들고 클리어 EXP에는 적용하지 않는다. 원작 MDF는 현재 RES와 단위가 달라 10으로 나눈 정수로 환산하며 미확정/충돌 효과는 제외 사실을 표시한다. 정확한 적용 범위는 [PC판 기준](langrisser2-pc-reference.md)에 정리한다. 상점·획득·전리품·자금 결제·영속 캠페인 인벤토리는 후속 구현이다. 랜덤 옵션·강화 확률·내구도는 도입하지 않는다.

후속 캠페인 설계에서 패배·재도전은 편성 직전 체크포인트로 돌아가고 작전비·장비·EXP를 복원한다. 현행 0.7은 정산 뒤 같은 맵 재연습 또는 패배 뒤 재도전에서 기존 성장·장비와 보상 기록을 유지하고 전장을 재배치한다. 첫 승리 전의 재도전은 첫 승리 보상을 받을 수 있으며 이미 보상한 시나리오의 EXP는 다시 받지 않는다. 별도의 `연습 초기화`는 전체 진행을 처음으로 돌린다. 지휘관 전투불능은 전투 내 부대 손실로 충분히 치명적이며, MVP에서는 다음 장 결장·치료비·영구 사망을 적용하지 않는다.

## 8. 어려운 상황을 만드는 방법

| 요소                | 일반                                | 전술                                                      |
| ------------------- | ----------------------------------- | --------------------------------------------------------- |
| 전투·경제 기본 수치 | 동일                                | 동일                                                      |
| 적 편성·시작 위치   | 대응 수단을 한 전선씩 배치          | 같은 병력 예산으로 두 전선의 위협을 겹침                  |
| AI                  | 목표와 지휘 범위를 지키며 개별 공격 | 용병으로 길을 열고 후속 유닛으로 지휘관 공격, 부상자 교대 |
| 증원·시간           | 대응까지 2라운드 여유               | 대응까지 최소 1라운드 여유                                |
| 보너스 목표         | 주 목표 가까이                      | 주 목표와 병력 분할을 요구                                |
| 저장·예측·재도전    | 자유 저장, 자동 복구, 정확한 예측   | 동일                                                      |

기본은 전술, 일반은 규칙 학습을 돕는 선택이다. 준비 화면에서 자유롭게 바꿀 수 있다. 게임 도중 변경은 해당 장 준비로 돌아가 적용한다. 수치 배율·저장 금지·불시 즉시 행동 증원으로 난이도를 올리지 않는다.

맵에는 **위협 두 가지 이상, 실행 가능한 대응 두 가지 이상, 무한 대기를 깨는 이유 하나**가 있어야 한다. 증원은 반복 무한 생성하지 않는다. 정찰에서 등장 칸·시점·행동 개시를 알리고, 발생 직전에도 맵에 표시한다. 좋은 보너스는 무손실만 강요하지 않고 시간·위치·선택을 요구한다.

적 AI는 공개 정보로 후보 행동을 평가한다. 목표 실패 방지 → 지휘관 생존과 부대 유지 → 처치·피해·상성 → 위치 개선을 고려하며, 가중치·성격을 콘텐츠로 둔다. 지휘관 처치로 제거되는 소속 용병의 전력도 평가한다. 실행 후 상태를 다시 계산해 이미 죽은 적에게 공격을 예약하지 않는다. 세부 계산 한도와 결정론은 [기술 설계](web-ux-tech.md)에 있다.

번호는 **1~6, 총 6전투**로 통일한다. 세계관은 초안의 오르덴·카이엘을 가칭으로 유지하되 첫 공개판은 국경 주민을 피난시키는 짧은 이야기로 완결한다. 루트·히든 직업의 잠긴 메뉴는 표시하지 않는다.

## 10. 개발 순서와 통과 기준

주당 10~15시간을 가정한 **추정 작업량**이다. 코드·도구·아트가 없는 현재 단계에서 출시 날짜를 약속하지 않는다. 각 단계가 끝나면 실제 소요 시간을 반영해 재산정한다.

| 단계                | 추정 시간  | 산출물                                        | 다음 단계로 갈 조건                                          |
| ------------------- | ---------- | --------------------------------------------- | ------------------------------------------------------------ |
| A. 코어와 임시 화면 | 30~45시간  | 이동·지휘·피해·반격·회복·승패, 임시 도트 맵   | 상세 규칙의 수용 사례 통과, 마우스로 1전투 가능              |
| B. 전투 검증판      | 40~60시간  | 2장 맵, AI, 정확한 예측, 짧은 연출, 복구 저장 | 정면 방어·봉화 차단 양쪽의 클리어 기록, 5명 플레이 관찰      |
| C. 성장 루프        | 45~70시간  | 편성·고용·18직업 전직·정산·세이브             | 편성 변경으로 같은 맵 해결법이 달라짐, 돈·EXP 중복 획득 없음 |
| D. 6장과 시각 정리  | 70~110시간 | 캠페인·2난이도·최종 도트·사운드               | 최소 편성으로 전 장 클리어, 장별 전술 차이 관찰              |
| E. 공개 준비        | 25~40시간  | 브라우저·성능·저장 QA                         | 성능 예산·복구·키보드 조작 검증, 진행 막힘 없음              |

합계 210~~325시간, 주 10~~15시간이면 약 14~~33주다. A~~B를 먼저 진행하고 재미 검증 전에는 C 이후의 콘텐츠를 대량 제작하지 않는다.

### 재미 검증의 기록

- 첫 실험은 5명 내외의 관찰 테스트다. 작은 표본의 승률을 전체 유저 통계처럼 해석하지 않는다.
- 플레이어가 지휘관을 옮기는 이유를 설명하는지, 부상 용병을 교대하는지, 적 지휘관 격파로 전선을 여는지 기록한다.
- 전투 중 “의미 없는 이동 클릭” 비중과 적 페이즈 대기를 측정한다. 25분을 넘기면 먼저 유닛 수·후방 행군·연출을 줄인다.
- 지휘관 단독 돌파, 전원 밀집, 시작 지점 무한 대기, 최상급 병종 일색 편성을 직접 시도해 만능 전략 여부를 확인한다.
- 정해 둔 정답 순서를 따라야만 이기는 맵은 재설계한다. 최소 두 개의 서로 다른 경로·편성으로 클리어를 재현한다.
- 결정론에서 같은 국면을 1,000회 반복하지 않는다. 다른 HP·지형·배치·행동 순서의 사례를 표로 비교한다. 봇 승률은 사람의 재미를 대신하지 않는다.

## 11. 보류 목록과 다음 작업

초안의 100직업, 5차, 성향·히든 전직, 다중 루트, 안개, 영구 사망, 온라인 랭킹은 모두 보류다. 부대 자동 이동도 경로 충돌과 오조작 비용이 크므로 먼저 개별 조작을 완성한다. 확장 순서는 3차 전직 → 12장 → 선택형 클라우드 저장을 후보로 한다.

현행 0.7은 규칙 코어·첫 맵·복구 저장·E2 작전·기존 두 자동 경로에 일반 마법 26종·소환 9종·아이템 34종·검증용 준비·기여 EXP·승리 정산·고정 성장·직업별 학습·전직·룬스톤을 더했다. 최종 통합 검증은 `handoff.md`에 기록한다. 사용자 요청으로 새 시나리오·E1/E3 전용 AI보다 공통 시스템을 우선한다. 다음은 고용·아이템 획득·상점·정식 준비를 작은 기능 단위로 연결한다. 마스터리·캠페인 장별 성장 속도 검증은 후속 범위다. 기존 미라의 최대 MP 9와 기본 능력치는 유지하고, 고비용 소환을 임의 MP 보정으로 먼저 열지 않는다. 각 기능은 현재 맵 또는 작은 규칙 테스트로 검증한다. 사람 플레이 관찰과 B의 통과 기준은 계속 미완료이며 계정·서버·최종 아트·100직업 확장은 보류한다.
