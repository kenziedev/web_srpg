- [x] R04 전장 조작: 전체 적의 물리 공격 위협 범위를 코어에서 구하고 오버레이로 표시한다. 임시 이동 위치의 지휘 범위·소속 보정을 표시한다. 줌과 키보드 타일 선택·행동·카메라 이동을 제공하며 모달과 단축키가 충돌하지 않는다.

## 실행 원칙과 수용 사례

1. 코어 명령은 실패 시 상태·로그·자금을 바꾸지 않는다. 준비 확정 후 구매·고용·마스터리 변경을 차단한다. 취소·미리보기·새로고침이 비용을 두 번 지불하지 않는다.
2. 연습 기록은 현재 초기 병력·각 아이템 1개·자유 마법 편성을 유지한다. 정식 기록에는 연습 자산·성장을 반입하지 않는다. 정식 기록은 현재 직업에서 배운 마법과 실제 구입·획득한 아이템을 사용한다.
3. 출격 중 죽거나 퇴각한 부대는 생존 할인에서 제외한다. 전직으로 고용할 수 없어진 계약은 만료한다. 전투 결과 화면과 다음 준비의 자금·계약이 일치한다.
4. 승리 보상 장부는 전투 재시작·저장/불러오기·재출격에도 유지한다. 실패 후 재도전은 성장·보상 중복을 만들지 않는다.
5. 마스터리는 기본 능력치를 누적 덧셈으로 오염시키지 않는다. 기사 마스터리는 해당 공격의 합법 이동 경로만 평가하며 제자리 공격·반격에는 이동 보너스를 주지 않는다.
6. 저장 오류·미지원 버전·다른 모드·상한 기록을 명확히 구분한다. 준비 복구는 실제 준비 시점까지의 완전한 검증 가능한 기록으로 돌아간다. 기존 공개 기록은 동의 없는 삭제나 버전 번호 바꾸기로 처리하지 않는다.
7. 위협 표시는 현재 공개 정보와 물리 공격 규칙에 한정하며 마법 피해나 미래 증원을 포함한다고 표현하지 않는다. 임시 UI 선택은 코어 저장 상태를 바꾸지 않는다.
8. 전체 검사 통과 후 변경이 없는 검사를 불필요하게 반복하지 않는다. 실패가 나오면 원인을 해결한 뒤 관련 검사를 다시 수행한다.

## 이번 완료와 분리하는 후속 작업

맵·6장 시나리오·추가 출격 캐릭터·E1/E3 전용 전술·난이도별 배치 제작은 사용자의 시스템 우선 지시에 따라 다음 콘텐츠 작업으로 남긴다. 미확정 원작 수치를 추측해 완전 복원으로 표시하지 않는다. 최종 아트·사운드·온라인·클라우드 저장은 별도 제품 범위다. 사람 5명 플레이 관찰, 실제 Safari/Firefox·저사양 기기 품질 평가는 자동 Chromium 검사로 대체하지 않고 미수행이면 명시한다. 0.7 진행 중 전투의 자동 마이그레이션은 전용 구버전 검증기 없이 제공하지 않으며 원본을 보존한다.
