# 전투 화면 아트 방향

2026-09-14: 구 PC판 랑그릿사 같은 고전 판타지 SRPG의 도트 전장, 병사 대형, 손그림 인물 초상과 청색·상아색·금색 창을 기준으로 한다. 게임 고유 인물·시나리오·규칙은 유지한다. 원작 게임에서 추출한 그림이나 로고는 사용하지 않는다.

## 현재 적용

- 지형·기본 병사는 Andre Mari Coppola / Toën의 **Medieval Strategy Sprite Pack v1.0** 원본 16px 그림을 사용한다. 풀, 연결 숲, 산, 도로, 강, 다리, 거점과 병종별 대형을 같은 팔레트로 구성한다. 화면 타일은 기존 48px, 전장은 20×15로 유지한다.
- 마법사·성직자는 같은 팩을 위한 **Exewin / Toen Characters Extension**의 두 원본 그림을 사용한다. 호송 마차·비병 날개·소환수와 지원되지 않는 병종은 기존 자체 도형을 사용한다. 지휘관 깃발·진영 표시·HP·행동 완료·선택·위협·지휘 범위는 기존 코어 상태 위에 표시한다.
- 카이엘·로엔·미라는 **ZeNeRIA29 / RPG Action**의 동일 화풍 초상 세 장을 각각 사용한다. 원본의 첫 표정을 SVG viewport로 표시하며 다른 유닛에는 기존 병종별 SVG 초상을 사용한다.
- 장비는 **Ravenmore 2014 Fantasy Icon Pack**, 마법은 **J. W. Bjerk의 Painterly Spell Icons**를 사용한다. 34아이템 중 27종은 종류별 원본 아이콘에 대응하고, 정확한 종류의 그림이 없는 7종은 자체 벡터다. 일반 26마법과 소환 9종은 모두 아이콘에 대응한다. 이미지가 같아도 이름·효과·장착 판정은 각각의 콘텐츠 데이터를 따른다.
- `classic-srpg.css`가 상단 메뉴·명령창·하단 HUD·각종 대화상자를 짙은 청색, 상아색 겹테두리, 금색 제목·선택 표시로 통일한다. 한글은 기존 시스템 글꼴을 유지한다.

## 출처와 구현

정확한 원본 URL·작가·라이선스·파일별 체크섬·사용 프레임·표시 변경은 [외부 그림 출처 장부](asset-sources.md)와 `apps/web/src/assets/vendor/`의 각 `SOURCE.md`에 기록한다. 원본 PNG 바이트는 편집하지 않고, 런타임에서 일부 프레임 선택·크기 조절·좌우 반전·대형 배치와 동작을 적용한다. 실행 화면의 **안내 → 그림 출처와 라이선스**에서도 크레딧과 원본·라이선스 링크를 제공한다.

`toenArt.ts`가 순수한 표시 프레임을 선택하고 `toenTexture.ts`가 Phaser 자산 로드·픽셀 캐시를 담당한다. `pixelTerrain.ts`는 원본 타일을 CanvasTexture에 합성하고 `pixelUnits.ts`는 같은 병사 프레임을 정지 유닛·이동 잔상에 그린다. 지형 텍스처는 최초 표시와 코어의 `terrainChanges` 변경 때만 다시 만든다. 원본 지형 다운로드가 실패하면 기존 자체 지형을 사용하여 전투를 계속할 수 있다.

상세 전투의 `DetailedBattle.tsx`는 같은 병사 그림을 상체와 하단 다리 영역으로 나누고, 달리기·무기 움직임·피격과 대형 접근을 결합한다. 원본 팩 자체에는 걷기/공격 전용 연속 프레임이 없다. 원래 피해 결과·병력 감소·반격·스킵·동작 감소 설정은 유지한다.

모든 이미지 경로는 Vite import를 통해 빌드 파일명과 `/srpg/` 경로를 사용한다. 외부 서버로 실행 중 이미지를 요청하지 않는다. 장비·마법 이미지는 보이는 창에서 지연 로드한다. 코어·콘텐츠·저장 포맷·규칙 버전 0.8에는 변경이 없다.

## 남은 아트 작업

- 고유 인물 전체와 적 지휘관의 전용 초상, 성장·전직별 복장.
- 병종·장비별 전용 걷기/공격/피격 애니메이션 원화와 소환수·마차의 완성 그림.
- 맵 추가에 맞춘 더 많은 지형 변형, 상세 전투 배경과 효과음·음악.

새 그림도 실제 사용 범위와 출처를 먼저 기록하며, 현재 코드 도형과 정적 원본을 완성된 전용 애니메이션으로 소개하지 않는다.
