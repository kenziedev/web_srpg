# 전투 화면 아트 방향

24px 논리 타일을 2배로 표시하는 고전 PC SRPG 화면을 기준으로 한다. 지형은 채도가 낮은 녹색·모래색·청록색, 아군은 청색, 적은 적갈색, 선택과 명령창 장식은 옅은 금색으로 구분한다. 글자는 시스템 한글 글꼴로 읽기 쉽게 유지한다.

## 현재 표현과 출처

이번 화면에는 외부 이미지·폰트·게임 원본 에셋을 사용하지 않았다. 저장소 안에서 작성한 코드 도형이며, 별도의 외부 에셋 라이선스 의존성이 없다.

| 파일 | 역할 |
|---|---|
| `apps/web/src/game/pixelTerrain.ts` | 24px 지형 도형: 풀, 수관·나무 그림자, 강둑·물결, 도로, 나무다리, 언덕, 회복소·봉화탑 |
| `apps/web/src/game/pixelUnits.ts` | 병사·기병 대형, 지휘관 깃발, 비병 날개와 호송 마차 |
| `apps/web/src/ui/Portrait.tsx` | 정수 좌표 SVG 초상: 투구형·궁병형·일반형과 진영별 배색 |
| `apps/web/src/ui/styles.css` | 청색 명령창, 금속 테두리, 작은 마름모 장식과 하단 HUD |

지형은 Phaser 장면 생성 때 한 번 그려 960×720 텍스처로 재사용한다. 행동·선택 때는 유닛과 범위만 갱신한다. 좌표 기반 무늬는 게임 규칙이나 난수를 바꾸지 않는다. 새 이미지 다운로드·음원·추가 라이브러리는 없다.

## 남은 아트 작업

현재 초상은 병종별 공통 도형이며 캐릭터별 완성 초상은 아니다. 병사 이동·타격 애니메이션, 장비별 외형, 마차 세부 표현과 지형 연결 변형은 후속 작업이다. 외부 에셋을 도입하면 이 문서에 원본 링크·작가·라이선스·수정 범위를 추가한다.
