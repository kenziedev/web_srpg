# 오르덴 연대기 (가칭)

지휘관과 용병을 따로 움직이며 지휘 범위, 병종 상성, 병력 회복과 전직을 활용하는 웹 SRPG. 작은 도트 그래픽과 짧은 조작으로, 매 전투에서 다른 전술을 고민하는 싱글 플레이 게임을 목표로 한다.

현재는 **첫 맵 전투 검증판** 단계다. 지도와 유닛을 보고 이동·공격·정비·회복을 미리 확인한 뒤 실행할 수 있다. 턴 종료, 기본 적 AI, 다음 라운드와 시작 회복까지 동작한다. 호송 이동·봉화 점령·증원·승패와 재도전까지 동작한다. 저장·캠페인은 아직 없다. 설계는 v0.2이며 밸런스는 플레이테스트 전의 가설이다.

## 실행

Node.js 24.x와 pnpm 11.1.2가 필요하다.

```sh
corepack enable
corepack prepare pnpm@11.1.2 --activate
pnpm install --frozen-lockfile
pnpm dev
```

브라우저에서 `http://127.0.0.1:5173`을 연다. 다른 AI나 개발자는 [AGENTS.md](AGENTS.md)와 [개발 인수인계](docs/handoff.md)부터 읽으면 된다. Claude용 진입 파일도 같은 규칙을 가리킨다.

유닛 선택 → 밝은 빈 칸 선택 → 적을 누르면 공격 미리보기 → 행동 확정. 대기·정비·회복은 우측 패널에서 선택한다. 회복을 누른 뒤 대상 아군을 선택한다. 지도는 드래그·휠로 이동한다. `Esc` 취소, `C` 지휘 범위 토글, `N` 다음 미행동 부대, `E` 턴 종료. 미행동 부대가 남으면 확인 후 종료하며, 기본으로 미행동 용병이 소속 지휘관을 따라 이동·공격한 뒤 적군 턴으로 넘어간다. 직접 대기·공격한 용병은 자동 행동에서 제외된다. 지휘관은 자동 조작하지 않는다. 우측 용병 자동 행동 옵션을 끄면 남은 행동을 포기하고 종료한다. 적 행동 후 다음 아군 턴으로 돌아온다. 적 턴 빠르게 옵션도 제공한다. 새로고침하면 초기화된다.

주 목표는 **10라운드 내 호송대 탈출과 카이엘 생존**이다. 도로의 도착 칸을 비우고, 북쪽 봉화는 지휘관으로 라운드 끝까지 점유한다. 2라운드까지 점령하면 보너스, 비병 등장 전에 점령하면 증원을 취소한다. 좌측 하단에서 호송 예정 위치·막은 부대·증원 상태를 확인할 수 있다.

우측 **전투 연출**에서 간략/상세를 선택한다. 간략은 기존 맵 위 연출, 상세는 양쪽 부대가 맞붙는 별도 교전창이다. 상세창은 건너뛰기 또는 Space/Enter/Esc로 닫을 수 있고, 빠른 진행 옵션도 적용된다. 선택한 연출 모드만 브라우저에 기억하며 전투 저장 기능은 아직 없다.

## 검증

```sh
pnpm check
pnpm build
pnpm sim:mission
pnpm exec playwright install chromium
pnpm test:e2e
```

`check`는 타입·규칙 테스트·콘텐츠 검증·결정론 재현 스모크·코어 의존성 경계를 확인한다. `build` 산출물은 `apps/web/dist`다. GitHub Actions에도 동일 검증 흐름을 정의했다. 원격 CI 실행 결과는 로컬 결과와 별도로 확인한다.

## 코드 구조

```text
apps/web/src/game     Phaser 지도 표현
apps/web/src/ui       React 화면과 입력
packages/schema      데이터 타입과 검증
packages/content     JSON 맵·유닛·지형·상성
packages/core        순수 이동·지휘·피해·명령 적용
packages/sim         브라우저 없는 명령 재현
tests/e2e            실제 브라우저 조작 검증
```
