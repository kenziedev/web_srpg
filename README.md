# 오르덴 연대기 (가칭)

지휘관과 용병을 따로 움직이며 지휘 범위, 병종 상성, 병력 회복과 전직을 활용하는 웹 SRPG. 작은 도트 그래픽과 짧은 조작으로, 매 전투에서 다른 전술을 고민하는 싱글 플레이 게임을 목표로 한다.

현재는 **설계 단계**이며 실행 가능한 게임 코드는 없다. 이번 개정은 2026-09-08 작성된 v0.2이며, 모든 밸런스 수치는 플레이테스트 전의 가설이다.

## 설계 문서

| 문서 | 읽는 목적 |
|---|---|
| [제작 계획 v0.2](docs/plan.md) | 방향, 범위, 성장·경제, 캠페인과 개발 순서 |
| [전투 규칙](docs/combat-rules.md) | 지휘·회복·상성·피해·턴 처리의 구현 기준 |
| [첫 검증 맵](docs/vertical-slice.md) | 배치, 목표, 적 행동, 검증할 전술 |
| [웹 UX·기술 설계](docs/web-ux-tech.md) | 픽셀 디자인, 조작, 성능·저장·코어 구조 |
| [초안 검토·변경 기록](docs/design-review.md) | 초안의 문제, 변경 이유, 레퍼런스 확인 범위 |
| [v0.1 원안](SRPG_제작계획서_v0.1.md) | 기존 세계관과 100종 전직 아이디어 보관 |

구현 시 v0.2 문서 묶음을 따른다. v0.1의 직업·캠페인·온라인 구상은 확장 후보이며 현재 필수 범위가 아니다. 전투 세부 규칙은 `combat-rules.md`, 첫 맵의 좌표와 시나리오는 `vertical-slice.md`가 각각 기준이다.

다음 개발 작업은 **한 맵에서 지휘 범위와 부상 용병 교대가 재미있는지 검증하는 전투 프로토타입**이다. 완료 기준과 순서는 제작 계획에 있다.
