# 오르덴 연대기 (가칭)

지휘관과 용병을 따로 움직이며 지휘 범위, 병종 상성, 병력 회복과 전직을 활용하는 웹 SRPG. 작은 도트 그래픽과 짧은 조작으로, 매 전투에서 다른 전술을 고민하는 싱글 플레이 게임을 목표로 한다.

현재는 **첫 맵 전투 검증판** 단계다. 이동·공격·정비, 구 PC판 일반 마법 26종과 소환 9종, 장비 2슬롯과 전투 전 마법 편성을 제공한다. 턴·적 AI·호송·봉화·증원·승패·재도전·자동 저장·새로고침 복구가 동작한다. 장비 33종과 소모 아이템 룬스톤을 지원하며, 전투 기여 EXP·승리 정산·고정 레벨 성장·직업별 마법 학습·18직업 전직을 제공한다. 정식 출격의 고용·상점·자금·생존 계약과 6계열 마스터리, 수동 3슬롯·출격 준비 복구·적 위협·줌·키보드 지도를 지원한다. 캠페인 장 제작은 후속 범위다. 실행 규칙 데이터는 **0.8**이며 밸런스는 사람 플레이 검증 전이다.

[남은 작업 실행 계획](docs/remaining-work-plan.md)에서 이번 공통 시스템 범위와 별도 콘텐츠 작업을 구분한다.

**정식 출격:** 상단 **정식 출격 열기**로 연습과 별도 기록을 연다. **출격 준비 · 상점**에서 작전비 1,200 안에 용병을 편성하고 장비 자금 300으로 필요한 장비를 산 뒤 출격을 확정한다. 정식 마법 편성은 직업·레벨로 배운 목록에서 고른다. 첫 승리 자금·물품·지원금은 한 번만 지급하며 생존 부대는 다음 출격에 20% 할인을 받는다. [경제 규칙](docs/operation-system.md)을 참고한다.

**마스터리와 복구:** 1차 Lv10에서 계열 패시브를 해금하고 성장 창에서 하나를 장착한다. **저장 · 복구**에 수동 3슬롯과 마지막 출격 준비로 돌아가기가 있다. 패배 뒤 재도전은 편성 시작 시점으로, 저장 창의 준비 복구는 출격 확정 직전 시점으로 돌아간다. 0.7 이하 기록은 이전 버전 원본 백업으로 보존하며 자동 변환하지 않는다.

**지도:** `T` 적 물리 위협, 지도 버튼으로 줌·부대 중앙·키보드 타일 선택을 제공한다. 지도에 포커스가 있을 때 방향키로 커서를 옮기고 Space로 타일을 선택한다. WASD는 카메라, Home은 선택 부대 중앙이며 Ctrl/⌘+휠은 줌이다. 임시 이동 위치의 지휘 범위와 보정을 표시한다.

## 실행

Node.js 24.x와 pnpm 11.1.2가 필요하다.

```sh
corepack enable
corepack prepare pnpm@11.1.2 --activate
pnpm install --frozen-lockfile
pnpm dev
```

브라우저에서 `http://127.0.0.1:5173`을 연다. 다른 AI나 개발자는 [AGENTS.md](AGENTS.md)와 [개발 인수인계](docs/handoff.md)부터 읽으면 된다. Claude용 진입 파일도 같은 규칙을 가리킨다.

유닛 선택 → 밝은 빈 칸 선택 → 적을 누르면 공격 미리보기 → 행동 확정. 대기·정비·회복은 우측 패널에서 선택한다. 회복을 누른 뒤 대상 아군을 선택한다. 지도는 드래그·휠로 이동한다. `Esc` 취소, `C` 지휘 범위 토글, `N` 다음 미행동 부대, `E` 턴 종료. 미행동 부대가 남으면 확인 후 종료하며, 기본으로 미행동 용병이 소속 지휘관을 따라 이동·공격한 뒤 적군 턴으로 넘어간다. 직접 대기·공격한 용병은 자동 행동에서 제외된다. 지휘관은 자동 조작하지 않는다. 우측 용병 자동 행동 옵션을 끄면 남은 행동을 포기하고 종료한다. 적 행동 후 다음 아군 턴으로 돌아온다. 적 턴 빠르게 옵션도 제공한다. 새로고침하면 마지막 저장된 전투를 이어간다. 이동 미리보기와 재생 중인 연출은 복구하지 않는다.

**마법:** 미라를 선택하고 이동 위치를 정한 뒤, **마법** 목록에서 힐 1·매직 애로우·파이어 볼·포스 힐 1을 선택한다. 보라색 사거리 안의 중심 칸을 누르면 효과 범위와 모든 대상의 HP·MP 변화를 예측한다. 파이어 볼은 빈 칸을 중심으로 지역을 공격하고, 포스 힐은 선택한 지휘관 또는 용병의 소속 부대 전체를 회복한다. 회복 단축 버튼도 힐 1을 사용한다. 확정 전에는 이동·MP가 바뀌지 않으며 Esc로 취소한다. 상세 모드에서는 별도 마법창에 동시 발동과 대상별 결과를 표시한다.

마법과 아이템의 기준은 **스팀 리메이크가 아닌 구 Windows PC판 랑그릿사 2**다. [PC판 기준·현재 적용 범위](docs/langrisser2-pc-reference.md)에 일반 마법 26종·소환수 9종·아이템 34항목의 조사 근거, 현재 처리와 원작 차이를 정리했다. 강화·약화·지형 파괴·불사 제거·텔레포트·재행동·소환이 같은 예측·실행·저장 경로를 사용한다. 수치·저항 성공 판정·소환 배치 등은 프로젝트 규칙으로 정한 부분이 있으며 원작 완전 재현을 뜻하지 않는다.

**전투 준비:** 첫 이동·행동 또는 턴 종료를 확정하기 전, 상단 **장비 · 마법 편성**에서 지휘관을 선택하고 소유한 무기와 방어구/장신구를 각각 하나씩 장착한다. 검증용으로 34종을 한 개씩 보유하며 같은 물건을 여러 지휘관에게 중복 장착할 수 없다. **연습 마법 편성**에서는 미라가 사용할 마법을 선택한다. 직업·레벨로 얻는 정식 학습 기록과는 별도다. 장비가 주는 소환은 해당 장비를 장착해야 목록에 나타난다. 장비 변경·마법 편성도 저장되며 각 출격의 첫 전투 명령 이후에는 변경할 수 없다. 룬스톤은 장착 목록에서 사용하지 않는다.

미라의 초기 최대 MP는 9이며 오브 장착 시 18이다. 최대 MP를 넘는 고비용 소환은 목록에 이유를 표시한다. 승리 후 레벨 성장으로 최대 MP와 학습 마법이 늘어나지만 연습 마법 편성 자체는 MP를 채우거나 능력치를 올리지 않는다. 메사이얀 소드는 소속 부대의 전투 기여 EXP를 2배로 만들며, 고정 클리어 보상에는 배율을 적용하지 않는다. 룬스톤은 성장 화면에서 2차 Lv10에 한 개를 소모한다. 텔레포트는 대상 부대와 도착 칸을 차례로 선택하고, 어게인은 시전자 외의 행동 완료 부대원에게 라운드당 한 번 재행동을 준다.

**성장 · 전직:** 상단 메뉴에서 지휘관의 직업·레벨·EXP, 전투 기여와 전직 후보를 확인한다. 전투 중에는 피해와 능력치가 그대로이며, 승리 후 한 번 정산해 레벨당 100 EXP로 성장한다. Lv10에는 후속 직업을 비교하고 확정할 수 있다. 전직은 기존 능력치를 유지하고 직업 보너스·이동·병종·지휘·마법을 반영하며, 확정 즉시 경로가 고정된다. 2차 Lv10의 룬스톤은 초기 직업 Lv1로 돌아가되 기존 성장과 학습을 유지한다. 승리 뒤 **성장한 부대로 다시 연습**하면 성장·장비를 유지하여 같은 맵을 시작하며, 이미 받은 시나리오 보상은 다시 지급하지 않는다. 패배 뒤 결과창의 **다시 도전**도 기존 성장·장비를 유지하며, 아직 승리하지 않은 맵의 첫 승리 보상은 받을 수 있다. 상단 **연습 초기화**는 성장과 진행을 모두 처음으로 돌리는 별도 동작이다. 초기 EXP 보정이나 전직 조건을 건너뛰는 조작은 제공하지 않는다. 자세한 규칙은 [성장 구현 기준](docs/growth-system.md)을 따른다.

주 목표는 **10라운드 내 호송대 탈출과 카이엘 생존**이다. 도로의 도착 칸을 비우고, 북쪽 봉화는 지휘관으로 라운드 끝까지 점유한다. 2라운드까지 점령하면 보너스, 비병 등장 전에 점령하면 증원을 취소한다. 좌측 하단에서 호송 예정 위치·막은 부대·증원 상태를 확인할 수 있다.

우측 **전투 연출**에서 간략/상세를 선택한다. 간략은 기존 맵 위 연출, 상세는 병사별 돌격·접전·피격과 회복 마법을 재생하는 별도 교전창이다(일반 4.2초 / 빠르게 1.5초). 상세창은 건너뛰기 또는 Space/Enter/Esc로 닫을 수 있고, 빠른 진행 옵션도 적용된다. 연출 모드는 브라우저에 기억하며, 확정 결과를 자동 저장하므로 연출 도중 새로고침해도 피해를 다시 적용하지 않는다.

상단 **저장 · 복구**에서 현재 전투를 JSON 파일로 내보내거나 가져오고, 직전 정상 자동 저장을 복구할 수 있다. 가져오기·복구는 현재 전투를 교체한다. 저장 중에는 다음 명령을 기다리며, 저장 실패는 하단에 계속 표시하고 파일 백업을 제공한다. 손상 파일·미지원 버전은 정상 저장을 바꾸지 않는다. 두 슬롯 모두 읽을 수 없으면 자동 덮어쓰기를 중지하고, **현재 전투 다시 저장** 또는 **연습 초기화**로 저장을 재개한다. 이전 규칙 버전(0.2~0.6)의 저장은 현재 버전에서 이어갈 수 없지만 **기존 저장 원본 백업**에서 최신·직전 JSON을 보존할 수 있다. 백업은 버전 변환이나 복구가 아니며 슬롯을 변경하지 않는다. 이 검증판은 최신/직전 자동 저장만 제공하며 수동 3슬롯·장 준비 체크포인트는 후속 단계다.

저장과 재연습은 전역 명령 1,024개 상한을 공유하므로 한 기록에서 무제한 반복을 보장하지 않는다.

macOS에서 개발 서버가 시작 메시지 후 멈추는 경우 `CHOKIDAR_USEPOLLING=1 pnpm dev`로 파일 감시를 전환할 수 있다. 같은 환경의 E2E에도 `CHOKIDAR_USEPOLLING=1`을 붙인다.

## 검증

```sh
pnpm check
pnpm build
pnpm sim:mission
pnpm exec playwright install chromium
pnpm test:e2e
```

`check`는 타입·규칙 테스트·콘텐츠 검증·결정론 재현 스모크·코어 의존성 경계를 확인한다. `build` 산출물은 `apps/web/dist`다. GitHub Actions에도 동일 검증 흐름을 정의했다. 원격 CI 실행 결과는 로컬 결과와 별도로 확인한다.

## 웹 배포

공개 경로는 `https://kenzie.kr/srpg/`다. `kenzie.kr`의 기존 GitHub Pages 블로그(`kenziedev/kenziedev.github.io`, `master`)의 `srpg/` 디렉터리에서 정적 파일을 제공한다.

`pnpm build:srpg`는 `/srpg/`를 기준으로 JS/CSS 경로를 생성하며 결과는 `apps/web/dist`다. 일반 `pnpm build`와 로컬 개발 주소는 그대로 유지한다. 배포는 검증한 소스 커밋을 먼저 푸시한 뒤 결과 파일을 블로그 저장소의 `srpg/`에 반영하고 해당 저장소의 **Build and Deploy** 워크플로가 완료되면 공개 URL에서 확인한다. 블로그 PWA의 `deny_paths`에는 `/srpg`를 등록하여 게임 파일을 블로그 캐시에 넣지 않는다. 소스 버전은 공개 `srpg/deployment.json`에 기록한다.

저장은 브라우저와 도메인별로 분리된다. 로컬 연습 기록을 공개 사이트로 옮기려면 **저장 · 복구**에서 JSON으로 내보낸 뒤 공개 사이트에서 가져온다.

## 코드 구조

```text
apps/web/src/game     Phaser 지도 표현
apps/web/src/ui       React 화면과 입력
packages/schema      데이터 타입과 검증
packages/content     JSON 맵·유닛·지형·상성·직업·고정 성장표
packages/core        순수 이동·지휘·피해·성장·전직·명령 적용
packages/sim         브라우저 없는 명령 재현
tests/e2e            실제 브라우저 조작 검증
```

복구 저장, E2 작전 전환, 두 자동 클리어 경로와 구 PC판 마법·소환·아이템, 기여 EXP·승리 정산·레벨업·전직을 구현했다. 다음은 **고용·아이템 획득·상점·정식 준비**를 작은 기능 단위로 연결한다. 검증용 인벤토리와 연습 마법 편성은 캠페인 경제를 대신하지 않는다. 현재 첫 맵의 검증 경로는 Lv10 전직까지의 성장 과정을 제공하지 않으며, 조건을 맞추기 위해 초기 EXP를 올리지 않았다. 새 맵은 시스템 기반 이후로 두고 사람 플레이·밸런스 검증을 별도로 진행한다.
